Proyecto de fichas médicas

¿De qué trata mi proyecto?

Bienvenido a nuestro sitio web de fichas médicas, un proyecto desarrollado con HTML5 en Visual Studio Code, diseñado para organizar y consultar información médica de manera clara, sencilla y ordenada.

El objetivo de este sitio es representar una herramienta digital que facilite el registro de datos generales de los pacientes, antecedentes médicos e información relevante para su historial clínico.

A través de un diseño práctico y accesible, este proyecto busca integrar la tecnología con el área de la salud, demostrando cómo el desarrollo web puede contribuir a mejorar la organización de la información médica.
